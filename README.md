## 使用方式

1. 在官网注册账号，登录后自动获得 API 密钥（apikey）。
2. 调用接口时携带 `apikey` 参数即可。
3. 所有接口统一返回以下结构：

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

### 通用状态码

| 状态码 | 说明 |
| ------ | ---- |
| 200 | 成功 |
| 403 | 拒绝 |
| 404 | 未找到 |
| 429 | 限速 |
| 500 | 服务器错误 |

## 接入示例

以 Python 为例：

```python

url = "https://api.xiaoyu17love.top/API/wzyd.php"
params = {
    "apikey": "你的API密钥",
    "type": "search",
    "word": "关键词",
}
response = requests.get(url, params=params)
print(response.text)
```
